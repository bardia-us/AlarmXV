# AlarmXV 1.2.0

This release focuses on Wake-up Checker reliability and Android distribution.

## Highlights

- Silent full-screen «هنوز بیداری؟» screen with a 60-second countdown.
- Fixes repeated Wake-up Checker cycles when only one check was configured.
- Keeps the Wake-up Checker dismissible while its silent notification remains.
- Moves the large ringing clock down for better spacing on edge-to-edge screens.
- Includes separately signed APKs for ARM64, ARMv7, and x86_64 devices.

## Which APK should I install?

- `arm64-v8a`: most modern Android phones and tablets.
- `armeabi-v7a`: older 32-bit ARM devices.
- `x86_64`: Android emulators and uncommon Intel-based devices.

All APKs are signed with the same AlarmXV release certificate.
